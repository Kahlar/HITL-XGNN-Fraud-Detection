2. DIAGNOSIS OF DEFECTS IN PREVIOUS REPORT
--------------------------------------------------------------------------------
Root Cause Analysis of Previous Output:
1. Abstract Displacement / Empty Section:
   - In the prior script, paragraphs from the source file were appended using
     `doc._body._element.append(new_p_elm)` rather than adding paragraphs in-place.
     In Word XML, appending directly to `_body._element` placed elements after the
     body section properties, causing all copied body paragraphs to detach from
     their section headers and stack at the very end of the document.
   - Consequently, the "ABSTRACT" page header was followed by an empty paragraph,
     leaving the abstract visually blank on page xi.
2. Table Displacement / Detached Captions:
   - Tables appended via `_body._element.append(new_tbl_elm)` were similarly
     relocated to the end of the file, leaving table captions in Chapters 2, 3, 4,
     and 5 followed immediately by next-level section headers without data rows.
3. Solution Implemented:
   - Engineered strict sequential XML insertion using in-place paragraph element
     transplantation and preceding-sibling table insertion (`addprevious`).
   - Every paragraph and table now appears in exact sequential order immediately
     below its corresponding heading and caption.
